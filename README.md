# Prima Konveksi - Premium Sports Apparel Landing Page 🎽⚽🔥

Landing page resmi **Prima Konveksi**, produsen pakaian olahraga (*sports apparel*) custom berkualitas tinggi yang mengkhususkan diri dalam pembuatan jersey sepak bola, futsal, e-sports, running, cycling, serta jaket tracksuit custom dengan teknik cetak sublimasi digital.

---

## 🌟 Fitur Utama

- **Hero Banner Dynamic & Sporty**: Tampilan visual dramatis dengan pesan utama *"LEVEL UP YOUR GAME"* dan tombol Call to Action (CTA) ke WhatsApp.
- **Sticky Glassmorphism Navbar**: Navigasi transparan dengan efek backdrop blur modern yang bertransisi halus saat digulirkan.
- **Spesifikasi Kain & Teknologi Sublimasi**: Demonstrasi visual keunggulan bahan (Dryfit, Anti-UV, Cepat Kering, Tinta Sublimasi Anti-Pudar, Jahitan Distro).
- **Galeri Portofolio Interaktif (Filterable Gallery)**: Katalog produk interaktif berbasis JavaScript untuk memfilter jersey berdasarkan kategori (*Sepak Bola / Futsal, E-sports, Running & Cycling, Jaket Tracksuit*).
- **Panduan Ukuran (Size Chart Guide)**: Tabel interaktif untuk panduan ukuran jersey pria dan wanita beserta tata cara pengukuran tubuh.
- **Alur Pemesanan Interaktif**: Panduan langkah-demi-langkah mulai dari konsultasi desain, DP, proses produksi, hingga pengiriman.
- **WhatsApp Order Link Generator**: Tombol pemesanan dinamis yang menyusun format pesan otomatis ke WhatsApp customer service.
- **Desain Premium & Responsive**: Tampilan *dark mode* sporty dengan warna utama hitam legam dan aksen merah menyala, presisi di berbagai ukuran layar (mobile hingga desktop).

---

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur halaman semantik dan SEO-friendly.
- **CSS3**: Vanilla CSS dengan *CSS Custom Properties (Variables)*, layout *Flexbox* & *Grid*, animasi mikro, serta efek *Glassmorphism*.
- **JavaScript (ES6+)**: Logika interaktif untuk filter galeri, navigasi responsif, tab size chart, dan pemformatan link WhatsApp.
- **Typography**: Google Fonts (*Outfit* / *Poppins*).
- **Icons**: Font Awesome / SVG Icons.

## 🚀 Cara Menjalankan Proyek

Proyek ini dibuat menggunakan teknologi web murni (HTML/CSS/JS) tanpa dependensi *build step* atau framework kompleks, sehingga sangat ringan dan mudah dijalankan.

### 1. Langsung via Browser
Buka file `index.html` menggunakan browser pilihan Anda (Google Chrome, Mozilla Firefox, Safari, Microsoft Edge, dll).

### 2. Menggunakan Local Server (Direkomendasikan)
Untuk pengalaman terbaik (efek smooth scroll dan konsistensi path asset):

- **VS Code Live Server**: Klik kanan `index.html` lalu pilih *Open with Live Server*.
- **Python Server**:
  ```bash
  python3 -m http.server 8000
  ```
  Akses via browser di `http://localhost:8000`.
- **Node npx serve**:
  ```bash
  npx serve .
  ```
